Who runs what. Configs live in `configs/`; plan and figure specs in `docs/followup-experiments.md`. Run each with `bin/run configs/{NN}.yaml --ngpus N`.

## Quang

**Focus:** every experiment that uses EAST-8B as the backbone. Populates Figs 1, 2, and 3 of the paper.

| # | Config | What it is | Eval sets |
|---|---|---|---|
| **01** | `configs/01_east_8b_curated.yaml` | EAST-8B backbone + curated corpus + self-annotation (OT). The "full recipe" line. | WMT15 · WMT22 · IWSLT17 · IWSLT15 |
| **02** | `configs/02_east_8b_machine_targets.yaml` | Same as 01 **but** targets are re-generated by EAST-8B (machine-translated) instead of human-authored. Isolates target quality. **Needs the retranslation preprocessing step — see config for status.** | WMT15 · WMT22 · IWSLT17 · IWSLT15 |
| **03** | `configs/03_east_8b_waitk.yaml` | EAST-8B + curated + **wait-k policy** (procedural chunks, no LM annotation). **Needs `wait-k` criterion added to `scripts/07_annotate.py`.** | WMT15 · WMT22 · IWSLT17 · IWSLT15 |
| **04** | `configs/04_east_8b_conv.yaml` | EAST-8B + curated + **Conversational SiMT** (Wang 2024, awesome-align chunks + multi-turn dialogue SFT). **Needs the conv-simt criterion + policy modules.** | WMT15 · WMT22 · IWSLT17 · IWSLT15 |

**Recommended run order:** 01 → 03 → 04 → 02 (leave 02 for last — it needs the retranslation preprocessing step wired up first). Each run: ~40 GPU-h annotation + ~12 GPU-h training + ~20 GPU-h eval on a single H200-class GPU.

**Deliverable per experiment:**
1. Populated `results/train/{tag}/final/` (SFT checkpoint).
2. Populated `results/eval/{tag}/*.json` (a JSON per test-set × direction × latency cell).
3. Populated `logs/{tag}/` — auto-written by `bin/run`. Contains `manifest.json` (git sha + hostname + GPUs + timestamps) and `stage_N_<name>.log` per stage.
4. **Push to HuggingFace Hub for cross-check:** `bin/11_push_to_hub --config configs/{tag}.yaml --private`. This uploads the checkpoint + tokenizer + config.yaml + logs/ + eval/ + auto-generated model card to `{your-org}/simt-{tag}`. Dipankar verifies by cloning and inspecting the manifest + logs.
5. A `LOG.md` entry: config, command, headline numbers, any surprises.
6. Regenerate figures via `bin/run configs/{tag}.yaml --stage 6`.

**Blockers you'll need to unblock as you go:**
- 03 (wait-k): add a `wait-k` branch to `scripts/07_annotate.py` — no LM forward pass, just emit chunks at k-token intervals per the `annotate.wait_k_per_latency` config field.
- 04 (conv-simt): add a `conv-simt` criterion (awesome-align chunks) + a `conv_simt_kcv` inference policy. Both new modules per `docs/followup-experiments.md` §Fig 2.
- 02 (machine targets): add `scripts/01b_retranslate_targets.py` — runs EAST-8B decode on every source in the pool, replaces the target column. See config header for interface.

## First-run checklist

Once, at the top of the project:

```bash
git clone https://github.com/dipankarsrirag/simt-tor-26.git
cd simt-tor-26
bash create-venv.sh
source .venv/bin/activate
cp .simtrc.example .simtrc
$EDITOR .simtrc                           # set SIMT_MODEL_BASE, SIMT_DATA_ROOT, SIMT_HF_CACHE
bin/01_download_training_data             # curated corpus (~12GB)
bin/02_download_wmt_test_sets             # WMT15/22 test sets
bin/03_download_iwslt_vi_test_set         # IWSLT15 vi-en test
bin/04_prepare_tokenizer --backbone biaofu-xmu/EAST-8B --output results/train/east_8b_curated/tokenizer
bin/05_probe_backbone --model_dir ${SIMT_MODEL_BASE}/EAST-8B
```

Then for each experiment (start with 01):

```bash
bin/run configs/01_east_8b_curated.yaml --dry_run       # inspect commands
bin/run configs/01_east_8b_curated.yaml --ngpus 1        # go
# ...watch, log to LOG.md, iterate
```

Cross-annotation experiments (06, 07) — skip Stage 2:

```bash
bin/run configs/06_gemma_4b_from_2b_annot.yaml --ngpus 1 --skip 2
```

Ping Dipankar when 01 lands so we can align on figure-generation before firing 02/03/04.

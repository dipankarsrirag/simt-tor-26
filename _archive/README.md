# _archive/

Single top-level home for everything from prior runs. Nothing here is regenerated by the current pipeline. Read only for provenance.

## Layout — one subdir per source directory it was extracted from

```
_archive/
├── docs/       docs that no longer describe current work
├── scripts/    Phase-1 / probe / smoke / superseded pipeline scripts
├── src/        pre-v6 SFT recipe module
├── jobs/       PBS wrappers from the v6b run + pre-organisation loose files
├── results/    every output artifact from the v6b run + Gate-1 sweeps
└── logs/       ~500 PBS stdout/stderr from the Aug 22-28 v6b eval sprint
```

Each subdir has its own `README.md` with per-file specifics; read those for details. Quick-reference below.

## When to look here

| Question | Look at |
|---|---|
| "Where are the current paper's BLEU/AL numbers?" | `results/v6b_gemma_2b/extrinsic/*.json` + `figures/phase2/*.png` |
| "How was Gate 1 decided?" | `results/phase1/gate1/gate1_report.md` |
| "How was τ = 0.30 chosen?" | `scripts/phase1_tau_sweep.py` + `results/phase1/phase1_tau_sweep*/` |
| "Reproduce v6b baseline evals" | `jobs/v6b_gemma_2b/{strategy_b_evals,east8b_evals}/*.pbs` (path rewrites needed: `results/phase2/…` → `_archive/results/v6b_gemma_2b/…`) |
| "How did v6 pivot to instruct backbones?" | `docs/phase2-sft-and-streaming.md` + `LOG.md` 2026-08-21 |
| "Debug a job that failed on Aug 22-28" | grep by job name in `logs/*.log` |
| "Method-formal paper spec" | `docs/method-formal.md` |

## Don't

- Don't fire archived PBS files without rewriting hardcoded paths — most reference `results/phase2/…` (moved) and `jobs/…` (moved).
- Don't import `src/sft_pre_v6.py` — use `src.train.sft` (which was `sft_v6.py`) in the live tree.
- Don't extend the archive READMEs — add new content to live `docs/` or a new `LOG.md` entry.

## Retention

Everything here is kept indefinitely for the paper's provenance chain and any reviewer-driven ablation requests. If you need to shrink the repo:
- The largest cost is `_archive/results/v6b_gemma_2b/{sft_*/final,annot_ot_*/matrices.jsonl}` — all gitignored, kept on disk only. Delete safely with `rm -rf` once the paper is accepted.
- `_archive/logs/` (~500 log files) — safe to `rm -rf` at any point; regenerable by re-firing archived PBS with paths corrected.

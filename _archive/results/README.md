# results/_archive/

Outputs from prior runs. Nothing here is regenerated by the current pipeline.

## `v6b_gemma_2b/` — the current shipping baseline
The complete artifacts of the Gemma-4-E2B-it v6b run (Aug 22–28). See `LOG.md` for the run narrative.

Highlights:
- **`extrinsic/`** — 798 JSON files, one per (dataset, model, latency, direction). Feeds `scripts/03_plot_bleu_al.py`.
- **`sft_multilingual_v6b_v2bal_v3_htgt/`, `..._v2bal_v3/`, `..._condA/`** — trained checkpoints. `final/` subdirs are gitignored; `sft_summary.json` + `train_indices.json` are tracked.
- **`sft_dataset_multilingual_v6b_htgt_final.json`** — 237,993-row SFT dataset (gitignored; regenerate via `scripts/02_build_sft_dataset.py`).
- **`multilingual_source_pool_htgt.json`** — 30K-per-direction human-target source pool.
- **`tokenizer-extended-v6/`** — Gemma-4-E2B tokenizer with EOR/EOW special tokens added (tokenizer.json gitignored, config tracked).
- **`annot_ot_multi_htgt_{de-en,en-de,ru-en,en-ru,ar-en,en-ar,vi-en,en-vi}/`** — per-direction annotator matrices (matrices.jsonl gitignored).

Note: `DELETED_MODELS_ARCHIVE/`, `_archive_summaries/`, `_archive_zh/`, `annot_ot_e4b_n10k/`, `annot_ot_qwen35_n10k/` are pre-v6b or abandoned-ablation dead ends kept only because deletion would break checksum manifests in `sft_summary.json` files.
